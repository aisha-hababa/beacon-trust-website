# Beacon Trust Website

A modern and responsive charity organization website built with HTML, CSS, and JavaScript.

The project was created as a learning project to practice frontend development, responsive layouts, interactive components, and UI implementation.

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Modern charity/non-profit landing page
- Light and Dark mode
- Responsive navigation bar
- Hero section with statistics
- About Us section
- Events section with interactive slider
- Contact form UI
- Floating support button with popup
- Scroll-to-top button
- Smooth scrolling
- CSS animations and hover effects
- Responsive mobile layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Grid
- CSS Flexbox
- CSS Variables
- Google Fonts
- Local Storage
